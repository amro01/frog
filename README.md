# 方块青蛙过河

一个简单有趣的HTML5小游戏，适合在工作间隙摸鱼放松。

## 🎮 在线游戏

点击下方链接即可开始游戏：
**https://amro01.github.io/frog/**

## 游戏玩法

### 难度选择
- 使用数字键**1、2、3**选择游戏难度：
  - **1** - 简单模式：速度较慢，障碍物较少，温暖鲜亮配色
  - **2** - 普通模式：平衡的游戏体验，默认配色
  - **3** - 困难模式：速度快，障碍物多，蓝紫色调配色
- 游戏中随时可以切换难度，当前关卡会重新开始

### 基本操作
- 使用**方向键**控制青蛙移动：
  - ↑ 向上移动
  - ↓ 向下移动
  - ← 向左移动（半格）
  - → 向右移动（半格）

### 游戏目标
帮助小青蛙安全穿过马路和河流，到达顶部的草地即可过关。

### 游戏元素
- 🚗 **马路**：避开来往的车辆，被撞到会死亡
- 🌊 **河流**：必须跳到漂浮的木头上才能安全通过
- 🐊 **危险**：在河里落水可能会被鳄鱼吃掉
- 🌱 **安全区**：草地是安全区域

### 游戏特点
- 三种难度模式，适合不同水平的玩家
- 随着关卡提升，游戏难度会逐渐增加
- 不同难度有独特的配色方案
- 简单模式50关、普通模式100关、困难模式150关后难度不再增加
- 记录你的死亡次数和死因统计
- 简洁的像素风格画面

## 摸鱼专用

这个游戏专为工作间隙摸鱼设计：
- 无需安装，直接在浏览器中打开即可游玩
- 游戏过程安静无声，不会打扰同事
- 界面简洁，看起来像是在认真工作
- 可以随时暂停和继续

## 注意事项

- 暂时不支持声音效果
- 游戏会自动保存你的最高关卡记录
- 死亡后按任意键可以重新开始
