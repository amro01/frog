# 方块青蛙过河

一个简单有趣的HTML5小游戏，适合在工作间隙摸鱼放松。

## 🎮 在线游戏

点击下方链接即可开始游戏：
**https://amro01.github.io/frog/**

## 游戏玩法

### 难度选择
- 使用数字键**1、2、3**选择游戏难度：
  - **1** - 简单模式：速度较慢，障碍物较少，温暖鲜亮配色
  - **2** - 普通模式：平衡的游戏体验，默认配色
  - **3** - 困难模式：速度快，障碍物多，蓝紫色调配色
- 游戏中随时可以切换难度，当前关卡会重新开始

### 基本操作
- 使用**方向键**控制青蛙移动：
  - ↑ 向上移动
  - ↓ 向下移动
  - ← 向左移动（半格）
  - → 向右移动（半格）

### 游戏目标
帮助小青蛙安全穿过马路和河流，到达顶部的草地即可过关。通过全部50关即可通关！

### 游戏元素
- 🚗 **马路**：避开来往的车辆，被撞到会死亡
- 🌊 **河流**：必须跳到漂浮的木头上才能安全通过
- 🐊 **危险**：在河里落水可能会被鳄鱼吃掉
- 🌱 **安全区**：草地是安全区域

### 游戏特点
- 三种难度模式，适合不同水平的玩家
- 随着关卡提升，游戏难度会逐渐增加
- 不同难度有独特的配色方案
- 50关通关后可解锁成就系统
- **🎯 成就保存功能**：通关后可以输入姓名并保存截图
- **📊 历史记录**：查看之前的通关记录和统计数据
- **⚡ 子弹时间系统**：在危险时刻触发慢动作效果
- 记录你的死亡次数和死因统计
- 简洁的像素风格画面

## 🎯 新增功能

### 成就系统
- **通关截图保存**：成功通关后可以保存包含游戏统计的个性化截图
- **玩家姓名记录**：输入你的名字，让成就更加个性化
- **历史记录查看**：查看最近10次的通关记录
- **本地存储**：所有记录都保存在浏览器本地，保护隐私

### Debug模式
- 按**D键**开启Debug模式
- Debug模式下按**V键**可一键通关（用于测试）
- 左上角会显示Debug状态提示

## 摸鱼专用

这个游戏专为工作间隙摸鱼设计：
- 无需安装，直接在浏览器中打开即可游玩
- 游戏过程安静无声，不会打扰同事
- 界面简洁，看起来像是在认真工作
- 可以随时暂停和继续
- 通关后可以保存成就，记录你的摸鱼成果！

## 🎮 操作说明

### 基本操作
- 使用**方向键**控制青蛙移动：
  - ↑ 向上移动
  - ↓ 向下移动
  - ← 向左移动（半格）
  - → 向右移动（半格）

### 特殊操作
- **数字键1-3**：切换游戏难度
- **D键**：开启/关闭Debug模式
- **Debug模式+V键**：一键通关（测试用）
- **回车键**：在姓名输入框中确认保存
- **ESC键**：取消姓名输入

## 📸 截图功能

### 如何保存成就
1. 成功通关50关后，点击"保存成就"按钮
2. 在弹出的对话框中输入你的名字（2-10个字符）
3. 点击"保存截图"按钮
4. 截图会自动下载到本地，文件名格式：`青蛙过河_你的名字_时间戳.png`

### 截图内容
- 完整的游戏画面
- 玩家姓名
- 游戏难度
- 死亡次数统计
- 通关时间
- 游戏版本信息

## 注意事项

- 暂时不支持声音效果
- 游戏会自动保存你的最高关卡记录
- 死亡后按任意键可以重新开始
- 截图保存功能需要现代浏览器支持
- 如遇保存失败，会提供备用方案
